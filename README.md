# realestate-virtual-tour

## Overview
This is a **real estate platform** where:
- Landlords can list rental/sale properties.
- Tenants can search and view properties with **virtual tours**.
- Users can **drag & drop furniture** to preview layouts.
- AI-powered chatbot helps with **rent negotiation**.

The MVP will first launch as a **web app**, later as a mobile app.

---

## Tech Stack
- **Frontend**: React + Tailwind + Three.js (for 3D tours)
- **Backend**: Node.js (Express) + PostgreSQL (or Supabase for faster setup)
- **Storage**: Supabase / DigitalOcean Spaces for property images & 3D models
- **AI**: OpenAI API (chatbot negotiation), Luma AI (photo → 3D experiments)
